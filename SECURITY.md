# Security and sensitive reports

Do not report secrets or exploitable details in public issues. After the public
repository is available, use GitHub private vulnerability reporting if enabled.
If no private channel is available, ask the maintainer to establish one without
including sensitive details. No response-time commitment is currently offered.

Blue Jackal observes a supported tool stream and independent acceptance results.
It is not a security sandbox and cannot establish absence of unobserved actions.
Native agent permissions remain the execution boundary. See docs/TRUST_BOUNDARY.md.

Reports and exports are local artifacts. Allowlisting and pattern checks do not
certify that arbitrary secrets are absent; review artifacts before sharing.
